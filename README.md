# Patient-level versus encounter-level validation for diabetes readmission

CSCI 550, Montana State University. Authors: Muhammad Shehzore Hashmi, Ahmad Sultan, Akshay Kumar Dosapati.

This repository accompanies Progress Report 2. It compares L2/L1 logistic regression, random forest and LightGBM across five seeds and two validation protocols. An unweighted logistic reference and constant-score baseline are included. Findings are historical benchmark results, not clinical validation.

## Reproduce

Use Python 3.12 and install `requirements.txt` in a virtual environment:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python run_experiments.py
python summarize.py
python verify_results.py
python generate_report_results.py
cd paper
pdflatex -interaction=nonstopmode -halt-on-error report.tex
bibtex report
pdflatex -interaction=nonstopmode -halt-on-error report.tex
pdflatex -interaction=nonstopmode -halt-on-error report.tex
```

The runner downloads the original UCI ZIP if `data/diabetic_data.csv` is absent. Data source: https://doi.org/10.24432/C5230J, CC BY 4.0. Cite Clore, Cios, DeShazo and Strack (2014). Raw data are not redistributed; retain the dataset's attribution and license when sharing derivatives. `results/audit.json` records the checksum.

The main run contains 500 candidate fits (10 partitions x 5 folds x 5 model variants x 2 candidates), 50 selected final fits, and 10 constant predictions. Runtime depends on CPU and numerical libraries. Two model threads are used. Five independent seeds can be run concurrently using `RUN_SEED`, then aggregate by running the ordinary command, which resumes completed partitions. Do not modify the protocol while reusing outputs: use a fresh results directory for a changed experiment.

## Protocol

- Exclude discharge codes 11, 13, 14, 19, 20, 21. Retain other encounters, including repeated patients and transfers.
- Target `<30` versus `>30`/`NO`; prediction point is discharge.
- Drop identifiers and weight. Preserve literal `None` laboratory values as not performed; preserve `?` separately as unknown.
- Eight numerical columns are standardized; other columns are one-hot encoded. Diagnoses use fixed clinical category rules.
- GroupShuffleSplit holds out 20% of patients. StratifiedShuffleSplit holds out 20% of encounters in the diagnostic arm.
- Seeds: 11, 23, 42, 67, 101. Five-fold StratifiedGroupKFold or StratifiedKFold inside the respective development partition.
- All preprocessing, class weights and embedded L1 selection fit on training folds only. No resampling in these completed runs.
- Select candidate by mean validation AP; choose F1 threshold using selected candidate's out-of-fold development predictions.
- Refit on development data, evaluate held-out data once. Record model-dependent selected settings and actual partition composition.
- AP is sklearn average precision, not trapezoidal PR area.
- Bootstrap: 1,000 patient-cluster replicates on prespecified patient holdout seed 42, identical clusters for all model comparisons. Intervals are conditional and exploratory; no multiple-comparison adjustment.

## Outputs

- `results/audit.json`, `missingness.csv`, `encounters_per_patient.csv`: completed audit.
- `results/metrics.csv`, `summary.csv`, `splits.csv`: per-run and aggregate evaluation.
- `results/tuning_*.json`: actual candidate fold scores.
- `results/predictions_*.csv.gz`, `partition_*.csv.gz`: generated locally; intentionally excluded from publication because they contain encounter-level records.
- `results/bootstrap.csv`, `seen_unseen.csv`: conditional uncertainty and descriptive overlap diagnostics.
- `figures/`: manuscript graphics, generated by `summarize.py`.
- `paper/`: IEEEtran manuscript source, bibliography, and compiled PDF.
- `GROUP_WALKTHROUGH.md`: plain-language explanation and review questions.

## Status and limitations

Completed: audit, repeated main comparison, unweighted reference, overlap diagnostics, bootstrap, calibration diagnostic.
Planned: SMOTENC, calibration correction, discharge/transfer and patient-weighted sensitivity, SHAP, demographic subgroup analysis. No causal, fairness, prospective-deployment, or external-validation claims are supported. Same-patient overlap and different case mix cannot be disentangled causally by the two split arms.

The initial sparse random-forest timing pilot was interrupted before producing final test results. Forest inputs were converted to dense float32 for faster fitting, with the same forest settings and study design. The L1 search was narrowed from C={0.1,1} to C={0.01,0.1} for runtime before final test scoring; L2 retains C={0.1,1}. The final run is identified by the per-seed logs; pilot `run.log` is retained only locally for provenance.
